# Picard iteration history (superseded run)

Part of the data repository for *A hybrid global–2D model for SF₆/Ar inductively coupled plasma
etchers with neural-network acceleration*.

`picard_reference_history.json` records a 20-iteration solve kept for reference. **It is not the
history figure 7 plots.** That figure is drawn from the `convergence_history` block of
`data/reference_case/summary.json`, which runs to 26 iterations, and its plotted values are in
`data/plotted_values/figure07/`.
